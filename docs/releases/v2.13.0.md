# v2.13.0

Two new machine-readable surfaces, a manual `switch` that now actually
revalidates a rate-limited account, and hardening around the selection counter
the runtime proxy watches. No user configuration migration is required.

Landed as [#688](https://github.com/ndycode/codex-multi-auth/pull/688),
[#690](https://github.com/ndycode/codex-multi-auth/pull/690) and
[#691](https://github.com/ndycode/codex-multi-auth/pull/691).

## Upgrade notes

No migration is required. Install the package and confirm the version:

```bash
npm i -g codex-multi-auth
codex-multi-auth --version
```

The command should report `2.13.0`.
